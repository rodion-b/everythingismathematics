# Everything is Mathematics

Friendly maths games for children aged 4 to 10, at [everythingismathematics.com](https://everythingismathematics.com).

Six games (counting, adding and taking away, times tables, shapes, patterns, fractions), each with a few levels, plus a "maths is hiding everywhere" section and tips for grown-ups. Stars are kept in the browser's `localStorage`; nothing is sent anywhere.

It's a static site with no build step: `index.html`, `style.css`, `app.js`. The colours are shared with [iamalena.com](https://iamalena.com).

Run it locally with any static server, for example:

```sh
python3 -m http.server 8000
```

Hosted on GitHub Pages from `main`; the custom domain is set by `CNAME`.
